# Mini Combate em Java

Este projeto é uma simulação simples de combate entre dois personagens utilizando Java e conceitos de Programação Orientada a Objetos (POO).

## 📌 Descrição

O sistema possui dois personagens:

- **Herói**
- **Vilão**

Ambos herdam atributos e comportamentos da classe base `Jogador`.

Cada personagem possui:

- vida
- ataque
- defesa

Durante o combate, os personagens podem atacar e defender, reduzindo a vida do oponente com base no cálculo de dano.

A simulação do combate ocorre na classe `Partida`.

---

## 🧠 Conceitos utilizados

- Programação Orientada a Objetos (POO)
- Herança
- Encapsulamento
- Interação entre objetos
- Classes e métodos

---

## 📂 Estrutura do projeto

Jogador (classe base)

Heroi (herda de Player)

Vilao (herda de Player)

Partida (classe principal que executa o combate)

---

## ⚔️ Exemplo de combate

O combate ocorre quando um personagem executa:

Heroi ataca Vilao  
Vilao perde vida conforme o dano calculado.
